# Aufguss Studio

Design a sauna infusion (Aufguss), round by round: length, temperature, room size, level, style, opening ritual, ice balls and scents, airing, music mood, and a waving technique for every phase. A library of named towel-waving techniques with an animated figure (the towel is simulated as cloth).

- `index.html` – the app (EN/DE, offline PWA, no accounts, no outside requests)
- `review.html` – numbered review page for techniques (1 …) and the grammar (G1 …)
- `techniques.js` – the technique database; `data.js` – grammar, options, rules; `demo.js` – figure + cloth simulation

Prototype, in review. MIT licence.
